--- SLIDE 6: Algorithmic Paper Generator (The DSA Engine) ---
- Title: Algorithmic Core: Deterministic Constraint Satisfaction
- Key Points:
  * O(1) Duplicate Pruning: Normalizes whitespace and lowercase characters into SHA-256 / MD5 hashes stored in a Set to eliminate duplicates instantly.
  * Inverted Candidate Indexing: Fast indexing using Map lookups keyed by Topic, Difficulty, and Question Type.
  * Multi-Objective Greedy Heuristic:
    Score(q) = W_topic * (Required) - W_reuse * (Times Used) + W_diff * (Target Match)
  * Bounded Backtracking Subset-Sum: Explores candidate combinations with early pruning to hit exact target section marks without overshooting.
- Visual: Flowchart illustrating the DSA pipeline: Filter -> Hash Deduplication -> Greedy Ranking -> Subset-Sum Backtracking -> Result Paper.
- Speaker Notes: "The core algorithmic innovation is our DSA Engine. Instead of random selection, it constructs candidate indexes using Hash Sets and Maps. It ranks eligible questions with a greedy variety score that penalizes overused questions and prioritizes uncovered topics, then employs bounded subset-sum backtracking to guarantee exact section marks."

  * Immutable Version Snapshots: When finalized, the paper creates a snapshot (v1, v2) in versionHistory, preventing accidental modifications to published exams.
  * Clear Error Diagnostics: Pinpoints exact deficiencies if the question bank lacks sufficient questions to satisfy constraints.
- Visual: Mockup of the Paper Detail page showing the 'Validate Constraints' report card (Passing marks ratio, Easy/Medium/Hard percentage progress bars).
- Speaker Notes: "Quality control is vital in academic testing. Our system provides an on-demand validation report card checking mark totals, difficulty percentages, and topic representation. Once approved, the teacher finalizes the paper, freezing an immutable snapshot in version history."
